# AirGuard SDGs Agent Guide

## Project Overview
- ML project predicting next-day PM2.5 for 10 Indonesian cities
- Focus: SDG 3 (Health), SDG 11 (Sustainable Cities), SDG 13 (Climate Action)
- Combines regression forecasting with interactive dashboard visualization

## Key Directories
- `data_mentah/` - Raw hourly data per city (generated by data collection script)
- `data_gabungan/` - Combined daily data (input for modeling)
- `models/` - Saved model files
- `src/data/` - Data collection scripts
- `notebooks/` - Analysis notebooks
- `dashboard/` - Dashboard implementation

## Essential Commands
**Data Collection** (run first if data missing):
```powershell
python src/data/ambil_data_airguard.py
```
Outputs: `data_mentah/*.csv` and `data_gabungan/airguard_harian_semua_kota.csv`

**Preprocessing** (creates modeling dataset):
- Handled in notebooks or modeling scripts
- Creates `data_gabungan/airguard_preprocessed.csv`

**Model Training & Evaluation**:
- Follow `MODELING_DASHBOARD_GUIDE.md` workflow
- Train time-series split: 2022-2024 (train), 2025 (validation), 2026 (test)
- Compare against persistence/rolling baselines
- Save outputs to `data_gabungan/`:
  - Predictions: `airguard_predictions.csv`
  - Metrics: `model_metrics.csv`
  - Feature importance: `feature_importance.csv`
  - Model: `models/airguard_model.joblib`

## Critical Constraints
- **Time series split required** - Never use random train/test split
- **Lag features must be per-city** - No cross-city contamination
- **Rolling averages cannot use future data** - Strictly historical
- **Target is next-day PM2.5** - Model predicts `pm2_5` for following day
- **Baseline comparison mandatory** - ML model must beat simple baselines
- **Avoid US_AQI as feature** - Too close to target (data leakage risk)

## Dashboard Requirements
- Uses same preprocessing pipeline as training
- Reads model outputs from `data_gabungan/`
- Shows: current conditions, next-day predictions, risk categories
- Visual elements: city map, rankings, historical trends, pollution episodes
- Risk categories must have documented thresholds (not medical claims)

## Verification Checklist
Before considering modeling complete:
- [ ] No missing values in target
- [ ] No future data in training set
- [ ] Lag/rolling features computed per city only
- [ ] Model performance evaluated vs baselines
- [ ] MAE, RMSE, R2 recorded for all models
- [ ] Predictions saved to CSV with required columns
- [ ] Best model saved with preprocessing pipeline
- [ ] Dashboard reads correct output files
- [ ] Prediction traceability to source data maintained
