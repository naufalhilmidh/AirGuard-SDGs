# AirGuard SDGs — Sistem Prediksi dan Pemetaan Risiko Polusi Udara di Kota-Kota Indonesia

Proyek ini dikembangkan untuk memenuhi tugas kelompok Minggu Ke-9 & 10[cite: 2] pada mata kuliah terkait Sustainable Development Goals (SDG's). Proyek ini berfokus pada **SDG 3 (Kehidupan Sehat dan Sejahtera)**, **SDG 11 (Kota dan Permukiman Berkelanjutan)**, dan **SDG 13 (Penanganan Perubahan Iklim)**[cite: 1].

---

## 📋 Deskripsi Proyek
Menganalisis pola PM2.5, perubahan kualitas udara, dan hubungan polusi dengan kondisi cuaca[cite: 1]. Model machine learning bertugas memprediksi konsentrasi PM2.5 pada hari berikutnya, sedangkan dashboard interaktif menunjukkan wilayah dengan tingkat polusi tinggi, tren, dan prediksi risiko[cite: 1]. 

**Nilai Proyek:** Kombinasi *machine learning*, analisis temporal, peta interaktif, dan informasi yang mudah dipahami masyarakat[cite: 1].
